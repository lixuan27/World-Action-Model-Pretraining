\section{Experiments}
\label{sec:experiments}
The evaluation connects reciprocal computation to control, transfer, and representation quality.
Each comparison isolates one step in this proposed relationship.

\subsection{Experimental setup}
JAM pretrains on DROID \citep{droid}, BridgeData V2 \citep{bridge}, and EgoDex \citep{egodex},
combining robot commands with human motion supervision from the first update. The model pairs a
pretrained video backbone with a newly initialized agent stream, totaling 6.02 billion parameters.
Foundation training uses eight H200 accelerators and global batch 512. Episode-level holdouts
separate training windows from open-loop evaluation. Downstream tests cover LIBERO \citep{libero},
RoboTwin 2.0 \citep{robotwin}, VLABench \citep{vlabench}, and RoboCasa365 \citep{robocasa365};
LIBERO-Plus \citep{liberoplus} and LIBERO-PRO \citep{liberopro} test distribution shifts.

Paired comparisons hold demonstrations, adaptation budget, samplers, and environment resets fixed.
Control uses task success; representation tests use frozen-world probes, perceptual prediction error,
and consequence displacement error. The planned protocol uses three training seeds with paired
bootstrap intervals. The evidence snapshot contains a completed 20,000-update direct-adaptation run
and foundation logs through update \FoundationSteps{}. These are measured optimization records.
External benchmark scores retain source attribution; JAM benchmark cells marked T are layout
targets awaiting evaluation. Appendix~\ref{app:setup} specifies data proportions, optimization,
evaluation manifests, and statistics.
