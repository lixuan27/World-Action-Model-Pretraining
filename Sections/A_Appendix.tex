\section{Reproduction Interface}
\label{app:repro}

A run is fully specified by its configuration overrides, so every row of the
study reduces to one command. Selecting the coupling family, the backbone, the
visual encoder and the visibility mode happens on the command line, and the
trainer records the resolved configuration next to the weights. Fine-tuning a
released checkpoint requires the path of that checkpoint and the identifier of
the target dataset. Deployment takes the checkpoint directory alone and starts a
server that speaks the observation and action protocol of \sref{sec:corpus},
after which each benchmark client runs inside its own environment. The
denoising trajectory, the executor mode, the replanning horizon and the velocity
cache are deployment-time settings, so reproducing any row of \tref{tab:q6} or
\tref{tab:cost} reuses one checkpoint and changes only the server flags.
