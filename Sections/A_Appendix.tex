\section{Reproduction Interface}
\label{app:repro}

A run is fully specified by its configuration, so every arm of \sref{sec:exp}
reduces to one command. A structured base configuration holds every default, a
data recipe file adds the sources with their hours, cameras, bindings, and
weights, a model preset selects the coupling, and one experiment file per arm
overlays the remainder; command-line overrides address any field by its dotted
path. The resolved configuration, the commit, and the data fingerprint are
written next to the weights, so the arm that produced a number is recoverable
from that number alone.

Three properties keep the arms comparable. The coupling axis changes one
attention mask and one stop-gradient, so its arms are parameter-matched without
further care. The cache key includes the source, the canvas, the window, the
normalisation, the codec, and the consequence layout, so an arm that changes any
of those rebuilds its cache, which keeps every arm bound to its own
preprocessing. Evaluation runs against a published checkpoint directory through
a standard client protocol, so the analysis code and the benchmark clients stay
independent of the training code.
