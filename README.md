# JAM: Action-Grounded World Pretraining

LaTeX manuscript for JAM, Joint Action–World Modeling. This revision reorganizes the paper around how action supervision can influence a pretrained world representation through reciprocal generative computation.

## Build the paper

The generated tables and vector figures are committed. Compile directly with either:

```sh
tectonic -X compile main.tex --keep-logs --keep-intermediates
```

or a standard TeX Live installation:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The output is `main.pdf`. The repository also includes a compiled reading copy in `paper/JAM.pdf`.

To regenerate numerical displays from the archived evidence and inspect consistency:

```sh
python3 -m pip install -r requirements-paper.txt
python3 scripts/build_artifacts.py
tectonic -X compile main.tex --keep-logs --keep-intermediates
python3 scripts/validate.py
```

The first Tectonic build downloads standard TeX packages. Subsequent builds reuse its cache. All diagrams are native TikZ; plotted figures are vector PDFs generated by Matplotlib. No external image service is required.

## Evidence snapshot

The source project was inspected read-only on 7 September 2026 at revision `9bb88f9dd77bf01d523c367991556ac0df7129d7`. The revision identifies the audit, not necessarily the commit that launched each run. Per-file hashes in `artifacts/provenance.json` identify the exact evidence used here. Training code, running jobs, and source data were left untouched.

Three evidence classes remain distinct:

- **Measured:** the complete 20,000-update LIBERO direct-adaptation training log, its numerical summary, and a fixed foundation-training log prefix through update 5,200. These document optimization, not closed-loop success.
- **External reference:** verbatim source-reported benchmark values under provenance identifier R1. `artifacts/external_reference.json` contains the exact immutable source URL, source SHA-256, table pointers, and original numeric strings. R1 is the external method identified at that URL; none of its measurements belong to JAM. Its source protocols remain separate from JAM's planned comparisons.
- **Planned:** `experiments/layout_targets.json` contains layout design values. Every displayed value is marked with a colored superscript T, and captions say that measurements are pending. Target curves are also labeled directly in the plot. These values are neither measured outcomes nor preregistered predictions.

The abstract and conclusion restrict empirical statements to available training evidence. Representation gains, synergy, robustness, conditional-sampler fidelity, and cross-embodiment transfer await controlled measurements. Additional acquired data is separate from the mixture already used in the archived run.

## Repository layout

- `main.tex`, `Sections/`: six main sections and an unnumbered appendix.
- `jam.bib`: verified source metadata, with exact paper URLs.
- `Figures/`: editable TikZ diagrams and vector plots.
- `Tables/`: generated numerical displays and snapshot macros.
- `artifacts/`: immutable evidence copies, sanitized resolved configurations, and provenance.
- `experiments/`: the protocol ledger and explicitly planned layout values.
- `scripts/`: artifact generation and validation.
- `docs/revision_audit.md`: implementation discrepancies and editorial decisions.

## Updating results

Keep the original measured file and record its hash before changing a table. Add a completed protocol, checkpoint identity, per-episode results, aggregation command, and uncertainty estimate to the ledger. Promote only those cells supported by the new artifact. A target value never becomes measured merely by removing its marker. Rebuild the displays, check citations and references, compile, and visually inspect every page.

The configurations in `artifacts/configs` are documentation snapshots with local asset paths replaced by logical names. They do not launch training independently. `experiments/protocols.json` points to actual source-project configurations and records pending implementation requirements for stricter controls. No training is launched by paper build scripts.

## External-source attribution

R1 links directly to the immutable public benchmark export rather than inventing a replacement paper title or author list. It denotes the external system, not an anonymous JAM baseline. Its full-suite results are contextual anchors until dataset partitions, demonstrations, reset lists, horizons, and aggregation rules are aligned. In particular, the source's RoboTwin clean-to-randomized average and randomized-only score are different metrics.
